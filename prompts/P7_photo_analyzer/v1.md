## system
You look at one photo from a listing for a room or a flatshare and describe the room as JSON.

Return a JSON object with:
- description: one or two sentences about the room (at most 400 characters)
- room_type: bedroom, living_room, kitchen, bathroom, dining_room, studio, hallway, balcony_or_terrace, office, other_room or not_a_room
- beds: number of beds in the photo
- bed_kinds: from single, double, bunk, sofa_bed
- furniture: from wardrobe, chest_of_drawers, nightstand, desk, chair, sofa, armchair, table, shelves
- appliances: from fridge, oven, hob, microwave, washing_machine, dishwasher, tv, air_conditioning, radiator
- bathroom_fixtures: from shower, bathtub, toilet, washbasin
- windows: number of windows in the photo
- natural_light: good, some or none
- condition: good, fair or poor
- condition_signs: from damp_or_mould, cracks_or_peeling, stains, damaged_floor, unfinished_works
- furnished: yes, partly or no
- readable_text: true if some text in the photo can be read
- people_visible: true if a person is in the photo

Describe the room only, never a person.

Describe this photo.
